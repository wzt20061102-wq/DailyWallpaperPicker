# 验证范围

本页区分原本机版本的已测行为与公开发布构建。原本机测试记录含个人路径和壁纸信息，不随公开仓库分发。此处只记录检查范围和边界，不用模拟数据冒充真实桌面验收。

## 已有自动化检查

预览最大化版本在开发电脑上编译成功，已有 **51 项离线检查通过**。源码中的 `SelfTests.cs` 包含这些检查，主要覆盖：

- 北京时间 22:50 / 23:00、跨日、跨年和错过多日后只补最近一期。
- 缓存复制与校验，包含隐藏文件、中文路径、空目录、文件集合和内容哈希。
- 越界路径、被修改或缺失的缓存、无效媒体与不支持的项目类型拒绝处理。
- 推荐日期隔离、过期下载结果、忙碌或重复操作、错误状态和暂停恢复。
- 最近 10 次选择、当前候选、当前壁纸与预览租用资源的清理保护。
- 悬停预览校验结果复用、资源释放、文件变动失效及同大小文件篡改识别。

这些检查使用临时样本和受控状态，不需要把真实工坊壁纸打包到测试目录。通过结果不等同于 Steam 下载、完整动态播放或重启登录的端到端测试。

## 既有本机人工验证

以下在一台 Windows 电脑、单屏、已登录 Steam 并安装 Wallpaper Engine 的环境中完成：

| 范围 | 已确认行为 | 边界 |
| --- | --- | --- |
| 工坊与缓存 | 查询、未订阅项目下载、复制校验及工作进程退出后使用副本 | 使用当时实际可用的作品，不代表所有工坊项目 |
| Video 悬停 | 预热后鼠标移入播放、移出暂停，同一时间只播放一张 | 首次预热仍需等待；没有跨设备性能保证 |
| 独立预览 | Video 与 Scene 默认最大化，保留还原和关闭按钮 | 只覆盖实际测试的作品与本机版本 |
| 桌面保护 | 下载、预览、关闭等过程中比对当前桌面路径和相关配置哈希 | 不是对所有系统、外部同时操作和异常条件的证明 |
| 明确选择 | 点击「使用这张」后读取当前壁纸核验，选择记录保存 | 没有在每次界面更新中重复切换桌面 |
| 本机生命周期 | 收起到托盘、恢复、退出及原本机登录任务手动启动 | 手动运行任务不等同真实重启后自动启动 |

## 公开发布构建

`0.1.0-preview.1` 在开发电脑上完成以下检查：

- 三个 x64 程序从公开源码构建成功；57 项程序检查全部通过。在原 51 项基础上增加封面成功、404、响应头超时、正文超时、无长度响应超限、非 HTTP(S) 地址拒绝等 6 项。本地 HTTP 夹具只连接回环地址，不调用 Steam。
- 32 项安装与自启脚本检查通过。文件复制实际执行于隔离目录，任务操作使用内存模拟；未实际注册、删除或运行 Windows 登录任务。
- 发布包从固定源码快照构建，公开源码包与该快照对应。ZIP 文件名集合和逐文件 SHA-256 校验通过；包内无用户数据、工坊媒体或 Steam DLL。
- 从解压副本首次执行只读 `--current`，确认自动发现本机 Wallpaper Engine、在程序旁新建数据目录并读回当前壁纸；前后桌面配置哈希一致。该检查没有打开新 UI、下载壁纸或更换桌面，不等于另一台电脑的首次完整流程。

本次发布所用 GitHub 授权不含上传 Actions 工作流的权限，因此未启用自动构建。`docs/windows-build.yml` 保留可选的 Windows CI 模板；具备相应授权后可放入 `.github/workflows/`。这里报告的是本地实际执行的结果，不是 GitHub CI 结果。即使启用 CI，未安装并登录 Steam 和 Wallpaper Engine 的运行器也不能验证真实工坊或桌面播放。
