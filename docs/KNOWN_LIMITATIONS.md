# 已知限制

当前版本适合在单屏 Windows 环境中试用。界面打开、进程运行或离线测试通过，都不代表所有电脑上的完整流程已经通过验收。

## 预览

- Video 支持鼠标悬停播放、移开暂停。第一次需要校验缓存并准备解码器，可能等待几秒；预热后响应更快，但不能保证每台电脑都“零延迟”。
- 为减少等待，选择窗口显示时最多保留三个已打开、暂停的视频播放器。高分辨率视频可能占用较多内存。已有单机测试中，两张高分辨率候选准备后，进程工作集约 1 GB；这只是一次实测值，不是上限或最低配置。
- Scene 暂不支持封面内动态悬停播放，使用静态封面和「预览」按钮。
- 完整预览由 Wallpaper Engine 独立窗口显示，默认静音并最大化。最大化只在打开时执行，可以手动还原；它不是独占全屏模式。
- 视频格式、解码器、显卡驱动和 Wallpaper Engine 版本会影响预览。失败时应显示原因并保留当前桌面。

## 屏幕、调度和安装

- 首版仅完成一台电脑的单屏验证。检测到多屏时拒绝应用壁纸和清理缓存，不支持多屏壁纸布局。
- 每日时间固定为北京时间 22:50 准备、23:00 提醒，当前没有时间设置界面。
- 需要程序运行，或启用可选的登录启动。程序不会唤醒电脑；错过提醒时只补最近一期。
- 真实物理重启后的登录启动、长时间休眠恢复、长期连续运行和真实系统 DPI 切换尚未完整验收。
- 发布版为便携 ZIP，不含通用图形安装器。新的便携启动和启动脚本与此前本机部署不是同一条安装路径，不能沿用原部署的测试结论。
- 不同 Windows 版本、Windows N / 精简系统、Steam 多库布局及未预装媒体组件的环境尚未全面测试。

## 推荐与下载

- 候选来自 Steam 创意工坊，查询结果和下载速度取决于 Steam、网络、地区与作品可用性。作品删除、改名、改标签或撤销公开后，结果可能变化。
- 全年龄筛选依据工坊标签，不构成人工内容审核。偏好参考标签、成功选用记录及明确的「不喜欢」反馈，不能保证每组风格都符合个人口味。
- 「不喜欢」只排除明确点过的作品，其他相似题材降低推荐权重。相似判断依赖作者填写的题材标签，不做图片识别；标签缺失或不准确时仍可能推荐相似画面。媒体类型、分辨率、HDR 等技术标签不作为不喜欢的题材学习。
- 近期热门、新作和经典各取一张，但不会强制三个作品的风格完全不同。
- 离线异常和跨日逻辑有自动化测试；真实退出 Steam、真实断网和下载途中断网恢复仍需更多实机验证。
- 未订阅项目通过 Steam 接口下载后，程序另存校验副本。Steam 管理的下载位置可能仍占磁盘空间；本工具只清理自己拥有的缓存。
